# 車況透視鏡｜系統原型

2026 和泰 AI 黑客松「運用 AI 再造 TOYOTA 下一代顧客售後服務體驗」參賽作品（團隊：獎金一大隊）的可操作原型。
所有車主、車輛、價格與成效數字皆為示意資料。

**線上展示：** https://你的帳號.github.io/carlens/

## 怎麼操作

| 操作 | 方式 |
|---|---|
| 自動播放全部 13 步（約 2 分鐘） | 左下「自動播放」，或空白鍵 |
| 下一步／上一步 | 「下一步」，或鍵盤 → ／ ← |
| 重新開始 | 重新開始鈕，或鍵盤 R |
| 跳到任一步 | 點左側步驟，再按「跳到此步」 |

除了自動播放，所有按鈕都能手動操作：預約、車體亮燈、AI 問答（可自己打字）、勾選項目、手寫簽名、技師改量測值、專員回覆等。
用手機開啟會自動切換成車主的 LINE 畫面。

## 啟用 Gemini（選用）

右上角齒輪 → AI 引擎選「Google Gemini」→ 貼上 Google AI Studio 的 API Key → 測試連線 → 儲存。
金鑰只存在使用者自己的瀏覽器，不會上傳；正式系統應改由後端代為呼叫。未啟用時使用離線示範引擎。

## 程式結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 打包好的完整原型（單一檔案，由 build.py 產生） |
| `src/data.js` | 示意資料：車主、車輛、量測值、原廠標準、價格與工時 |
| `src/core.js` | 規則引擎（嚴重度判定）、報價、完工時間推算 |
| `src/ai.js` | Gemini 串接、離線示範引擎、AI 護欄（安全／保固 → 轉真人） |
| `src/owner.js` | 車主端：LINE 聊天室、Flex 訊息、LIFF 頁面 |
| `src/console.js` | 服務廠工作台 |
| `src/dash.js` | 成效儀表板、系統架構、痛點分析 |
| `src/story.js` | 13 步展示流程與自動播放 |
| `src/art.js` | 原創 SVG 圖示與俯視車體 |

修改 `src/` 後執行 `python3 build.py`，會重新產生 `index.html`。
